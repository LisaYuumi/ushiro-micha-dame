# 「うしろ見ちゃダメ!」ゲームデザイン相談用まとめ(AI に渡す用)

## お願い
家族・友だち向けのオンライン「ハンカチ落とし」ゲームを試作しています。
下のルールと試遊の結果をもとに、**ゲーム性をもっと面白くするアイデア**と、**今の問題点の直し方**を提案してください。
提案するときは、次の3つも一緒に書いてください。
- 子ども(小学生くらい)にもわかるか
- スマホの小さい画面で操作できるか
- 今のルールのどれを変えるか

## ゲームの核
- 「自分の後ろだけが見えない」ハンカチ落とし。周りの人には、誰の後ろに落ちたかが見えている。
- 周りの人はスタンプで**本当を教える**ことも、**嘘でだます**こともできる。反射神経のゲームを、心理戦・読み合いにしたい。
- 毎ラウンド、ひそかに**鬼の手下**が1人いる。スタンプには送り主が出るので、「だれが何を言ったか」から、自分に落ちているかどうかを勘ではなく推理できるようにしたい。
- 1試合5〜10分。友だちや家族で何試合も遊ぶ。言葉が通じなくても遊べるのが目標(スタンプは顔・記号・音)。

## 遊ぶ形
- スマホのブラウザで遊ぶ(横向き)。人数は **8人(席7つ+鬼1人)** か **5人(席4つ+鬼1人)** を選べる。足りない席はボットが座る。
- オンライン:ホストが部屋を作り、4桁の合言葉でほかの人が入る。ホストのスマホがルールを動かす。
- オンラインでは鬼は人だけがやる。ボットが負けたときは、座っている人の中から次の鬼を選ぶ。
- ひとり(ボット相手)でも遊べる。
- ボットには性格がある(せっかち/慎重/うたがい屋/おしゃべり)。名前の横に出る。

## 1ラウンドの流れ
1. 全員が輪になって内側を向いて座る。鬼が輪の外側を歩く。座っている人(ボットも含む)から1人が、ひそかに「鬼の手下」になる。
2. 鬼は、席の後ろを通るたびに1.5秒立ち止まる。毎回止まるので、止まっただけでは落としたかどうかわからない。
3. 鬼が誰かの後ろにハンカチ(落とし物)を落とす。
4. 落とされた人が気づいて振り向くと、そのまま拾って立ち上がり、鬼を追いかける。
5. 次のどれかでラウンドが終わる。
   - 鬼が空いた席に座れたら、鬼の勝ち。
   - 鬼にタッチできたら、追いかけた人の勝ち。
   - 鬼がもう一周して戻ってくるまで気づかなかったら、気づかなかった人の負け。
6. 勝敗が出たら、手下がだれだったかを全員に発表する。
7. 負けた人が次の鬼になる。

## 鬼の手下
- 手下であることは、本人の画面にだけ出る。オンラインでは、ホストは手下本人にだけ知らせ、ほかの人の端末には勝敗が出るまで送らない。
- 手下は、両どなりを含めて、ほかの全員の後ろに落ちた物が見える。自分の後ろだけは、ほかの人と同じく見えない。
- 手下はスタンプでだますと点になり、教えても点にならない。鬼が勝つと +2点(下の点数の表)。

## 1試合=5ラウンド、落とし物がだんだん重くなる
- 落とし物は、ハンカチ → 上履き → ランドセル → 机 → 教卓 の順。
- 重いほど、次のようになる。
  - 置く音が大きく、低く、遠くまで聞こえる(ばれやすい)。
  - 拾って走る人が遅くなる(教卓で約7割)。
  - 落とすまで鬼も少し遅くなる(教卓で約8割)。
  - 大きい物は頭の上にかついで走る(見た目で笑える)。

## 座っている人ができること
- **振り向く**:1ラウンドに **2回まで**。後ろに落ちていれば、振り向いた瞬間にそのまま拾って追いかける(「拾う」ボタンはない)。使い切ると、本当に落とされても拾えない。
  - 後ろに何もないのに振り向く(外れ)と、回数が1つ減るだけ。減点はしない。外れの回数は、表情の変化と、だました人(手下・鬼)の点数に使う。
  - 「振り向く」ボタンは、まん中に回る矢印(↻)、右上の角に残りの回数の数字バッジ(白い丸に黒枠)。0回になるとボタン全体が灰色になって押せない。押している間だけ振り向き、そのあいだボタンが沈む。
  - 振り向いた姿は全員に見える。
  - 追いかけっこ中と勝敗が出たあとは、回数を気にせず振り向いて見物できる。
- **スタンプ**:人(か名札)をタップすると、その人の頭の上に4つの選択肢が半円に並ぶ。選ぶと送れる。同じ人か外をタップすると閉じる。送れる数に上限はないが、**同じ相手には1ラウンド1回**。
  - 種類と見た目(文字ではなくアイコン+記号。落とし物アイコンはそのラウンドの落とし物に変わる):
    - 落ちてる:落とし物アイコン+「!」(見ろ)
    - まだ平気:落とし物アイコン+「×」(見るな)
    - ニセかも:落とし物アイコン+「?」(見るな。まだ平気と同じ扱い)
    - 信じて:うるうるした目の顔+「!」(見ろ)
  - 押したときに短い声(ハッ/シーッ/ん?/うるっ。仮の音)が鳴る。
  - **送り主が出る**:届いたスタンプには、送った人の名前と体の色が付く。
  - **1人に同時に3つまで**届く(早い者勝ち)。1つ1つ、**鬼が半周歩いたら消え**、空いた枠に次が届く。
  - 枠がいっぱいで届かなかったときは、その相手への1回は使わない(あとでまた送れる)。
  - **8人のときは、両どなりには送れない**(手下も同じ)。送れない相手(両どなり・このラウンド送った人)は名札が薄く、タップしても反応しない。
  - **5人のときは、両どなりにも送れる**(ただし後ろは見えないので、当てずっぽうになる)。
  - **鬼もスタンプを送れる**。
  - 自分あてのスタンプは、左下に白い札で届いた順に3つまで積み重なり(札には送った人の色の丸・名前・スタンプのアイコン)、届いた瞬間に画面のふちが光る。ほかの人あては、その人の名札の上にアイコンが並ぶ(アイコンの輪の色 = 送った人の色)。
- **バナナの皮**:追いかけっこ中だけ、1ラウンド1個。鬼か追いかける人のどちらかを選んで、その人の2.5m前の通り道に落とす。踏むと1秒転ぶ。曲がればよけられる。

## 鬼ができること(人が鬼のとき)
- 自動で歩く。スティックで速く・ゆっくりできる。「止まる」で立ち止まる。
- **落とす**:いちばん近い席の後ろに落とす(1ラウンド1回)。4周しても落とさないと、自動で落ちる。
- **落とす音**:落とさずに、本物とまったく同じ置く音だけ出す(何回でも)。近くのボットがときどきだまされて振り向く。
- **声**:咳/口笛/手拍子/叫ぶ。声を出してから0.8秒以内に落とすと、置く音がかき消されて小さくなる。声は1.5秒に1回まで。
- **スタンプ**:座っている人に送れる(だますと +1点、教えても点にならない)。
- 気づかれたら自動で走り、内側/外側にハンドルを切る。

## 追いかけっこ
- 追う人も鬼も、自動で同じ向き(輪を回る向き)に走る。操作は内側/外側に寄るだけ。逆走と待ちぶせはできない(待ちぶせで必ず勝ててしまったため)。
- 内側を走るほど近道。追う人のほうが少し速い(秒速3.3m、鬼は3.0m。重い物を持つと遅くなる)。
- 1m以内に近づいたらタッチ。

## 点数(1試合の合計で順位)
| できごと | 点 |
|---|---|
| 鬼が空いた席に座れた | 鬼 +3 |
| 鬼にタッチした | 追いかけた人 +3 |
| 負け(座られた・タッチされた・気づかなかった) | 負けた人 −3、次の鬼 |
| 鬼が勝った(席に座れた・最後まで気づかれなかった) | 手下 +2(手下が負けた本人のときはなし。そのときは −3 だけ) |
| スタンプで教えた・だました(鬼が相手の後ろを通ってから10秒以内に送ったものだけ) | 下の表 |

スタンプの「教えた」「だました」は、次のとおり。相手の動きは、そのスタンプが表示されている間(鬼が半周するまで)で判定する。

| 送ったスタンプ | 本当は | 相手の動き | 判定 |
|---|---|---|---|
| 落ちてる/信じて | 落ちていた | 振り向いた | 教えた |
| 落ちてる/信じて | 落ちていない | 振り向いて外れ | だました |
| まだ平気/ニセかも | 落ちていない | 振り向かなかった | 教えた |
| まだ平気/ニセかも | 落ちていた | 振り向かなかった | だました |

点数は、送った人の役で変わる。

| 送った人 | 正しく教えた | だました |
|---|---|---|
| 普通の人 | +1 | 0 |
| 手下 | 0 | +1 |
| 鬼 | 0 | +1 |

- 点が入ったお知らせは、送った本人にだけ出る(手下がばれないように)。

## 見え方と手がかり(後ろが見えない仕組み)
- 自分の画面には輪の内側しか映らない。
- **両どなり**の人の姿は見えるが、その後ろに落ちた物は自分の画面には映らない(手下だけは見える)。
- **向かい側**(両どなり以外)の人の後ろは見える。ただし、小さいハンカチは人や椅子の陰で見えにくく、大きい物は見える。
- 背後の手がかりは次の3つ。
  - **足音**(鬼のいる方向から聞こえる)
  - **置く音**(重い物ほど大きい。声でかき消されることがある)
  - **鬼の影**(鬼が後ろ3m以内に来ると、自分の前の床に影が映る。近いほど濃い。止まれば影も止まる)
- 顔:外れの振り向きをするたびに顔が崩れる(困り眉 → 汗・ちぐはぐな目 → 3回目から放心顔)。全員から見えるので、焦っている人がわかる。

## ボットの今の動き
- 性格は4つあり、名前の横に出る。正直さは役で決まるので、性格はそれ以外を変える。
  - せっかち:早く気づく。スタンプ1つで振り向きやすい。
  - 慎重:気づくのが遅い。「見ろ」が2つ以上そろわないと振り向かない。スタンプを送るのも少なめ。
  - うたがい屋:スタンプをあまり信じない。
  - おしゃべり:スタンプをたくさん送る。
- 後ろに落とされたことを最初から知っていて、1.5〜55秒のどこかでランダムに拾う(重い物ほど早い、声でかき消されると遅い、性格で変わる)。手がかり(止まった・音・影)とは関係なく動いている。
- スタンプは、鬼が10秒以内に後ろを通った人のうち、表示中のスタンプが少ない人に送る(落とされた人だけに集まらないように)。
  - 普通のボット:見える相手にはだいたい本当(9割)。5人のときの両どなりには当てずっぽう。
  - 手下のボット:だいたい嘘(7割)。ときどき本当も混ぜる。
  - 鬼のボット:ときどきスタンプを送る。だいたい嘘(7割)。
- スタンプを受け取ったボットは、表示中のスタンプの多数決(「見ろ」+1、「まだ平気」−1)で振り向くかを決める。前のラウンドの手下が送ったスタンプは、0.3票として数える。振り向ける回数が残り1回のときは、もっと票がそろわないと振り向かない。
- 鬼の声や「落とす音」にも、ときどきだまされる。
- ボットは、鬼が自分の後ろを一度も通っていないうちは振り向かない。鬼が後ろを通ってから5秒たつまでも振り向かない(気づいたとき・声や落とす音・スタンプのどれでも)。置いた瞬間に振り向かれると、逃げる鬼にバナナを置く間がなくなるため。5秒より前に届いたスタンプは、5秒たったところで考え直す。
- 追いかけっこは内側を走り、鬼に近づいたら鬼のほうへ曲がる。バナナはときどき投げる。
- ボットの鬼は、決まった速さで歩いて、ランダムな相手にランダムなタイミングで落とす。

## 試遊でわかったこと(家族で遊んだ結果と、それで変えたこと)
- 毎回つい振り向いてしまう → 振り向きは2回まで、がまんの +1点、鬼の影を追加した。→ 試遊のあと、お手つきの減点とがまんの +1点はなくし、「回数制限だけ」にした。
- 音で落とした場所がすぐわかる → ハンカチの音は小さく。鬼は毎回止まる。声で音をかき消せる。
- スタンプが全部嘘になりそう → 教えた得とだました得を同じ +1 にした。点数になるのは鬼が通った直後だけにした。
- 両どなりが丸見えだった → 人は見えるが、後ろの物は見えないようにした。
- **いちばんの課題:歩く人の動きとスタンプのやり取りが速すぎて、考える暇がない** → 鬼の速さを 1.6 → 1.0 → 0.7 m/秒にし、止まる時間を1.5秒、スタンプ表示を5秒にした(まだ効果は試していない)。いまのスタンプは、鬼が半周するまで表示される。
- 子どもは「もっと人数が多いほうがいい」 → 8人にした(5人も選べる)。
- ボットの動きがイマイチ → 性格を付け、スタンプの多数決で振り向くようにした(まだ試していない)。
- 自分に落ちたかどうかが勘になる → 鬼の手下、送り主の表示、1人に3つまで、同じ相手に1回、8人のときは両どなりに送れない、を入れた(まだ試していない)。

## まだ決まっていないこと・相談したいこと
1. 考える時間をどう作るか。例:鬼が止まるたびに全員が考える時間を作る、など。
2. ボットをどうすれば「人っぽく」、読み合いの相手になるか。手がかり(止まった・音・影)に反応する、など。
3. だます得と教える得のバランス。誰も信じなくなる/教えすぎて鬼が勝てない、のどちらにもならないようにしたい。今は「普通の人は教えて得、手下と鬼はだまして得」。
4. 試遊のあとで決めること:ラウンド後に手下を当てる投票/8人のときに手下を2人にする/1人が1ラウンドに送れるスタンプ数の上限。
5. 鬼の工夫(声・落とす音・止まる・速さ・スタンプ)が、座っている側の読み合いと噛み合っているか。
6. 1試合の長さ(今は1周約46〜49秒、5ラウンド)。
7. 企画書にはまだ入れていない案:ニセのハンカチ(本物は1枚だけ、ニセを拾ったら外れ)、舞台ごとの落とし物セット(海辺・お城など)。

## 見た目のルール(A案「放課後ポップ」)
- 全体:明るくポップ。すべてのキャラ・小物・家具に太い黒(#1E1B18)の輪郭線。陰影はリアルにせず、3段階のアニメ塗り。リアルな影は落とさない(スマホで軽くするため)。
- 色:空・壁の上 #8FD3E8/床 #F6C945(設定で持つ。舞台ごとに変えられる)/主要ボタン #FF6B4A/文字・輪郭 #1E1B18/札とボタンの地 #FFFFFF。
- 舞台:教室(ハンカチ落としのために机を下げた放課後の教室)。背景はキャラより少し落ち着いた色。床に近いほど少し暗く、部品ごとに少し色むらを付けて立体感を出す(色ごとに1つの形にまとめて描くので軽い)。
  - 床:少しずつ色のちがう床板を、継ぎ目をずらして並べる。窓から日差しの帯が差しこむ。
  - 壁と天井:下は腰板と幅木、上は水色。角の柱。天井と蛍光灯。
  - 前:黒板(チョークで「うしろ見ちゃダメ!」と波線、日付と日直、ラウンドごとに変わる落書き)、教卓、時間割表、学級目標「なかよく げんきに がんばろう」、時計(1ラウンドで10分進む)、スピーカー。
  - 窓側:窓の外に校庭と木、窓台に植木鉢、ピンクのカーテン。
  - 後ろ:ランドセルの入ったロッカー、後ろの黒板(きょうの めあて・マグネット)、掃除用具入れ。ロッカーの左右に、下げた机を並べ、椅子を逆さに乗せている。
  - 廊下側:ドアと掲示板(習字「友」「夢」「花」と絵)。
  - 家具の角は少し丸く(面取り)。キャラと下げた机の足もとに、ぼんやりした丸い影。
- 小さな動き:キャラはときどきまばたきする。走ると足もとに土ぼこり。拾ったときは頭の上に「!」、外れの振り向きで「?」、転ぶと「★」がポンと出る。自分が勝つと紙吹雪。
- フォント:M PLUS Rounded 1c(太字、SIL Open Font License で同梱)。
- 画面:説明文は出さない。文字は札とボタンだけ。
  - ボタン:白地かオレンジ地、黒い太い枠、角丸、右下にずらした黒い影。押すと影が消えて沈む。いちばん大事な操作(振り向く・止まる・落とす)はオレンジ。
  - 左上:ラウンド(黒い札)・いまの落とし物・自分の点数(自分にしか見えない)・鬼の周回(鬼のとき)。手下のときは、その下に紫の「あなたは鬼の手下」(本人の画面だけ)。手下になった瞬間は、紫のふちの白いカードがポンと出る(「あなたは鬼の手下!」「だまして +1点」「鬼が勝てば +2点」「ほかの人にはないしょだよ」。3秒で消える)。
  - 最初の画面:名前と体の色の下に、大きいボタンを2列(「ひとりで遊ぶ」「人数」「部屋を作る」「部屋に入る」)。
  - 右上:⚙ボタン。開くメニューに「やり直し」「役を変えて新しい試合」「上から見る(確認用)」「ボットの性格を表示: オン/オフ」「あそびかた」(操作とキーボードの説明)。
  - ボットの性格(「(せっかち)」など)は、ふだんは出さない(⚙メニューで切りかえ、端末に保存)。
  - ジョイスティック:立っているとき(鬼・追いかける人)だけ出す。座っている間は出さない。
  - 画面の端(iPhone の角の丸みやカメラ部分)から 40 ピクセル内側に収める。
  - ほかの人の点数は、プレイ中は出さない(点の動きで手下がばれないように)。ラウンドが終わるたびに結果カードを出す:可愛い見出しと一言(「タッチ成功!」「すわられちゃった…」「気づかなかった〜!」など)、全員の点数(このラウンドで増えた分つき)。結果カードが出ている間は、名札とゲーム用のボタンは隠す(⚙は残す)。結果カードは、左に得点表、右に裏向きの手下のカード(紫に「手下はだれ?」「?」「タップでめくってね」)。手下のカードをタップすると、そのカードだけがくるっと裏返り、左に手下のキャラの絵(体の色の人型が手を下ろして立つ、にやっとした顔)、右に「鬼の手下は… ○○! だったよ!」(鬼が勝ったら +2点の札)が出る。もう一度タップで裏向きに戻る。試合の終わりは順位のカード(1位に★)。結果カードの「次へ」ボタンで次に進む(ホストとひとりのとき)。
  - 自分あてのスタンプ:左下に白い札で3枚まで。
- キャラ:人型。丸い頭・カプセルの胴・短い手足(指なし)。顔は点の目と線の口で、外れの振り向きで崩れる。体の色はロビーで10色かカラーコードで選ぶ(暗い色なら顔の部品は白)。名前もロビーで決める(8文字まで、端末に保存)。
- 名札:頭の上に白地・黒枠の丸い札、黒い文字。画面に重ねた 2D で出すので、距離に関係なく同じ大きさ。画面の端で切れないように内側に寄せ、重なりそうなときは上にずらす。画面の外にいる人の名札は出さない。自分の名札は自分の画面には出さない。黒板は名札と重なりにくいよう高めにある。
- 動き:骨組みと動きは CC0 素材(Quaternius「Universal Animation Library」)。座る(少し揺れる)・立ち上がる・歩く・走る・座り直す。振り向きは頭→上半身の順に少し遅れて回る。バナナで転ぶと、物理演算でぐにゃっと倒れて(約0.7秒)、元の動きに戻って起き上がる(約0.35秒)。
- カメラ:座っているときは自分の頭の少し後ろ・上から(0.6m後ろ・1.8mの高さ、見える幅100度。5人のときは80度)。両どなりは画面の端に少し見えるだけで、輪の全体と正面の人の顔が見える。振り向くと頭の位置から後ろをのぞく。鬼のときは鬼のすぐ後ろ(1.7m後ろ・2.1mの高さ)。追いかけるときは少し離れた後ろ。
- 撮影モード(開発用):⚙メニューの「撮影モード」(キーボードは P)。SNS 画像や宣伝素材の見本を撮る画面で、ひとりで遊ぶときだけ開ける(開いている間ゲームは止まる)。無地の背景(6色)にキャラ1体。向き(正面・横・後ろ・斜め前)、表情(ふつう・困り眉・汗だく・放心)、ポーズ(座る・立つ・走る・転ぶ=倒れたまま)、体の色(10色)、カメラの近さを切りかえる。「UIを消す」でキャラだけを大きく映せる(タップで戻る)。「輪の場面」で6人が輪になって座るところを斜め上から撮れる。本番では GameConfig.SHOW_PHOTO_MODE を false にして隠す。
- 素材の出どころとライセンスは docs/CREDITS.md。
