# 「うしろ見ちゃダメ!」ゲームデザイン相談用まとめ(AI に渡す用)

## お願い
家族・友だち向けのオンライン「ハンカチ落とし」ゲームを試作しています。
下のルールと試遊の結果をもとに、**ゲーム性をもっと面白くするアイデア**と、**今の問題点の直し方**を提案してください。
提案するときは、次の3つも一緒に書いてください。
- 子ども(小学生くらい)にもわかるか
- スマホの小さい画面で操作できるか
- 今のルールのどれを変えるか

## ゲームの核
- 「自分の後ろだけが見えない」ハンカチ落とし。周りの人には、誰の後ろに落ちたかが見えている。
- 周りの人はスタンプで**本当を教える**ことも、**嘘でだます**こともできる。反射神経のゲームを、心理戦・読み合いにしたい。
- 毎ラウンド、ひそかに**鬼の手下**が1人いる。スタンプには送り主が出るので、「だれが何を言ったか」から、自分に落ちているかどうかを勘ではなく推理できるようにしたい。
- 1試合5〜10分。友だちや家族で何試合も遊ぶ。言葉が通じなくても遊べるのが目標(スタンプは顔・記号・音)。

## 遊ぶ形
- スマホのブラウザで遊ぶ(横向き)。人数は **5〜10人**(席4〜9つ+鬼1人。はじめは8人)をロビーの「− 8人 +」で1人ずつ選べる。足りない席はボットが座る。
- オンライン:ホストが部屋を作り、4桁の合言葉でほかの人が入る。ホストのスマホがルールを動かす。
- オンラインでも、負けた人が次の鬼(ボットが負けたら、そのボットが鬼。ボットの鬼はホストの端末で自動で歩いて落とす)。試合の最初の鬼だけは、人の中からランダムに選ぶ。
- ひとり(ボット相手)でも遊べる。
- ボットには性格がある(せっかち/慎重/うたがい屋/おしゃべり)。名前の横に出る。

## 言語
- 日本語と英語に対応。最初は端末の言語に合わせる(日本語なら日本語、それ以外は英語)。ロビーの 🌐 ボタンか ⚙メニューで切りかえられ、端末に保存する。
- 画面の文字はすべて翻訳ファイル `assets/i18n/texts.csv`(Godot の翻訳機能)にまとめてある。一覧は `docs/TRANSLATIONS.md`。言語を足す手順もそこに書いてある。
- スタンプは種類(落ちてる・平気・信じて)で送り、受け取った人の画面で、その人の言語で出す。英語は「Behind you!😨」「You're safe👍」「Trust me🥺」。自作の言葉は、受け取った人と言語がちがうときは、受け取った人の言語の初期の言葉で出す。
- 英語は文字が長くなるので、決まった幅のボタンは文字を小さくして収める。

## 音(音は遊びの一部。後ろが見えないぶん、耳が手がかり)
- 明るくポップで、少しコミカルな音。言葉の入った声は使わない(「ハッ」「うん」など言葉でない声だけ)。タイトル画面に「🎧 イヤホン推奨」。
- 音はすべて `tools/audio/make_sounds.py` で合成したオリジナル(`assets/sounds/*.ogg`)。同じ名前のファイルを置けば差しかえられる。AI が書いたプログラムで作ったので、Steam では AI 生成コンテンツとして申告する(docs/CREDITS.md)。
- **落とし物の音**:落とし物ごとに重さに合った音(ハンカチ「ふわっ」/上履き「ポトッ」/ランドセル「ドスッ」/机「ガタン」/教卓「ドーン」)。重いほど大きく、遠くまで聞こえる。**鬼の「フェイク」は本物と完全に同じ音**(同じファイル・同じ大きさ・同じゆらぎ)。どちらも落とした場所から聞こえる立体音響。
- **鬼の足音**:「トッ、トッ」(背景の音にうもれないよう、高めでくっきり。BGM はラウンド中は小さめ)を鬼の体から鳴らす(立体音響で、後ろの左右どちらにいるかがなんとなくわかる程度)。大きさと聞こえる広さは GameConfig(FOOTSTEP_VOLUME_DB・FOOTSTEP_UNIT_SIZE)で変えられる。鬼が自分で出せる音はフェイクと、教室の黒板消しの「ポンポンポン」(当てた人の場所から鳴る)。
- **座っている人**:振り向く「バッ!」(自分は大きく、ほかの人はその場所から小さく)/お手つき「シーン…」+「ぽわわ〜ん」/体育座りに移る「とぼとぼ」/拾って立つ「シュッ・ぽん」。
- **追いかけっこ**:鬼も追いかける人も速い足音/障害物で「ずでーん」/バナナで「つるっ」/鬼が最後の1周に入ると「ピコーン」/タッチ「パシッ✨」/鬼が座れた「ストン」。
- **スタンプ**:😨「ハッ!」/👍「うん!」/🥺「うるうる」(言葉ではない声)。送った人と、受け取った人にだけ聞こえる。
- **試合の流れ**:ラウンド開始のチャイム(オリジナルの音の並び)/手下の正体発表「ジャジャーン」/勝ち・負けのジングル(鳴っている間は BGM を止める)/試合の結果のファンファーレ/ボタンの「ポッ」。
- **BGM**:ロビー・結果は明るい曲、ラウンド中は控えめで少し緊張感のある曲(小さめ)、追いかけっこはテンポの速い曲。**教室のラウンド中は、小学校っぽい曲**(リコーダーのメロディ・木琴の低い音、2ラウンド目から鍵盤ハーモニカの和音とカスタネット、最後のラウンドはタンバリン。ハ長調のドレミソラで、音を短く切ってぬき足さし足のドキドキ感。bgm_school_1〜3)。**海辺のラウンド中はハワイアン**(はずむリズムのウクレレの「ジャン・ジャカ」、ハワイアン・スチールギターの、すべって入りゆれながらのびるメロディ、ベース。コードは F・D7・G7・C7 のハワイアンの決まった流れ。2ラウンド目からイプ(ひょうたんの太鼓)、最後のラウンドは歩くベースとシェイカー。88〜98bpm。bgm_beach_1〜3。前はスチールドラムとレゲエ風の裏打ちだったが、カリブっぽかったので変えた)。海辺のラウンドの始まりは、チャイムのかわりにウクレレのジャラ〜ンとスチールギターが「ポワ〜ン」とすべり上がるジングル(beach_start)。ラウンド中の曲は -15 dB くらい(前の -21 dB では小さすぎて、鬼が歩いている間は止まったように聞こえた)。曲を続けて切りかえても音が消えたままにならないように、切りかえの途中のフェードは止めてから次へ進む。ラウンド中の曲は、試合の進み具合だけで変わる(1〜2ラウンド目→3〜4ラウンド目→最後のラウンドで楽器が増え、少し速くなる)。**鬼との距離では変えない**(BGM で鬼の場所がわかってしまうため)。
- **環境音**:遠くの校庭のざわめき、時計のカチコチ(時計から)、ときどきカーテンの音(窓から)。ごく小さく。
- **音量**:ロビーの 🔊 と ⚙メニューの「🔊 音の大きさ」で、「全体」「BGM」「効果音」のスライダー。端末に保存する。
- Web 版はスレッドなしで書き出していて、音は Godot が自分で混ぜる STREAM 方式で鳴らす(ブラウザの「サンプル再生」は Android の Chrome で鳴らなかった)。性能の低いスマホやアプリの中のブラウザ(LINE など)で音が震える(とぎれる)のを減らすため、短い効果音は圧縮しない WAV、BGM と環境音だけ OGG にしている。音の出力の余裕(output_latency)は、Android・Windows・Linux のブラウザだけ 80 ms にしている(`output_latency.web_android` など。初期の 15 ms では、画面の処理が少し重いだけで音がとぎれて PC でも Android でもガタガタに割れた)。**わかったこと(2026/11 の試遊)**:Web 版は音を混ぜる処理も絵と同じ流れで動くので、絵を描くのが遅い PC(Windows の省エネモード・Chrome が GPU を使えていない)では、画面が映っている間だけ音がガタガタ割れる(隣のタブにすると音はなめらか)。Steam などのアプリ版では、音が別の流れで鳴り GPU も直接使えるので、この問題はほぼ起きない。調べるときは、ブラウザの開発者ツールのコンソールに5秒ごとに出る `perf`(fps・worst・sync・game・draws など)と、重い瞬間の `slow …` の行を見る。GPU を使わずに CPU だけで絵を描くブラウザ(SwiftShader など。会社の PC の設定で起きる)では、自動で「軽い動き」にする(1秒30コマまで・ロビーに直し方の案内)。3D を粗く描いて引きのばす方法は、GPU のない PC でかえって重くなり音も割れたので、PC ではやらない。**画面が細かいスマホなど(devicePixelRatio 1.5 以上)だけ**、遊んでいる間に4秒ごとの平均が40コマより少なければ、3D の細かさを 1.0→0.8→0.65→0.5 と一段ずつ下げる(文字・ボタンはそのまま。上げはしない。`AUTO_QUALITY_*`、main の `_auto_quality`。コンソールに `auto quality: …`)。**描く回数の軽量化(2026/11)**:キャラの体(頭・胴・手足の14部品)を骨といっしょに動く1つのスキンメッシュにまとめた(1人 約30回→約5回)。椅子は1脚ずつ1つの形に、背景の箱は色を頂点に持たせて輪郭線の太さごとにまとめた(StaticBatch。頂点の色の RGB が色、A が明るさ)。10人の教室で 1フレームの描く回数が 約500→約160。音の「なめらか」も自動ではオンにしない。🔊の画面に「音の鳴らし方: ふつう / なめらか(お試し)」があり、なめらかにするとブラウザに音を混ぜてもらう方式(サンプル再生)になる(画面の処理が重くても音がとぎれにくい。前に全員をこの方式にしたら Android の Chrome で鳴らなかったので、選んだ人だけ)。iPhone は初期のまま(150 ms にしたら鳴らなくなったため。全部の Web に `output_latency.web` をかけない。iPhone のブラウザ情報には「Mac」の文字が入るので、Mac 用の指定 web_macos も使わない)。
- **既知の制限**:性能の低い一部の Android(例: FCG01 / arrows We)では、全部の音が震える(描画に追われて音を混ぜるのが間に合わない)。対応は見送った。直すなら「画質を下げる軽いモード」か「スレッドありの書き出し」(GitHub Pages では特別な設定が必要で、iPhone で鳴らなくなる心配がある)。
- スマホのブラウザは、最初に画面をタップするまで音が鳴らない。タイトル画面(ロビー)のボタンを押したときから鳴り始める。

## 1ラウンドの流れ
1. 全員が輪になって内側を向いて座る。鬼が輪の外側を歩く。座っている人(ボットも含む)から1人が、ひそかに「鬼の手下」になる。
2. 鬼は、席の後ろを通るたびに1.5秒立ち止まる。毎回止まるので、止まっただけでは落としたかどうかわからない。
3. 鬼が誰かの後ろにハンカチ(落とし物)を落とす。
4. 落とされた人が気づいて振り向くと、そのまま拾って立ち上がり、鬼を追いかける。
5. 次のどれかでラウンドが終わる。
   - 鬼が空いた席に座れたら、鬼の勝ち。
   - 鬼にタッチできたら、追いかけた人の勝ち。
   - 鬼がもう一周して戻ってくるまで気づかなかったら、気づかなかった人の負け。
6. 勝敗が出たら、**教室のまま手下を当てる投票**(下の「手下を当てる投票」)。投票が終わると、手下がだれだったかを全員に発表し、ルーム主が「次へ」を押すと次のラウンドへ(ラウンドごとの結果ページはない)。
7. 負けた人が次の鬼になる。試合の最後だけ結果ページ(合計点と優勝者)を出す。

## 鬼の手下
- 手下であることは、本人の画面にだけ出る(左上の紫の札と、画面の四すみの紫のカギ形。ラウンドの間ずっと)。オンラインでは、ホストは手下本人にだけ知らせ、ほかの人の端末には勝敗が出るまで送らない。
- 手下は、両どなりを含めて、ほかの全員の後ろに落ちた物が見える。自分の後ろだけは、ほかの人と同じく見えない。
- 手下はスタンプでだますと点になり、教えても点にならない。鬼が勝つと +2点(下の点数の表)。
- **7席以上(8人以上)のときは、3回に1回くらい手下が2人**(`MINION_TWO_MIN_SEATS`・`MINION_TWO_CHANCE`)。手下どうしはおたがいを知らない。1人か2人かは**鬼だけが知る**(鬼の左上に紫で「今回の手下は○人(だれかはひみつ)」、2人のときはお知らせも出る)。鬼も手下がだれかは知らない。オンラインでは、手下の人数は鬼の端末にだけ送る。

## 手下を当てる投票(教室のまま。話し合いの時間を兼ねる)
- 流れ(GameState の `vote_wait` → `voting_open` → `reveal_left`(0 で「次へ」待ち)→ ルーム主の「次へ」で `next_round`。ルールを動かす人だけが進める):
  1. 勝ち負けの演出: 画面を切りかえず、見出しと一言をポンと出す(`VOTE_INTRO_TIME` 2.2秒。見逃しのときは見逃しの演出のぶん `MISSED_SCENE_TIME`)。
  2. 投票: カメラが自分の席のうしろの少し高いところへなめらかに動き、輪の全員と名札が見える。上の白い札に「鬼の手下は誰?」「4/6人 投票済み」と案内。人(か名札)をタップして投票し、入れた人の名札の上に「あなたの票 ▼」。**全員がそろうまでは入れ直せる**。投票した人の名札は緑の「✓」(だれに入れたかは見せない)。残り時間は出さない。
     - **手下以外の全員(鬼も。鬼は手下がだれか知らない)**が投票する。自分と鬼には入れられない。手下には「あなたは手下。バレないように!」。
     - 全員が投票したら、すぐ発表。ルーム主(ひとりのときは自分)にだけ下に「発表へ ▶」。投票が始まって5秒たってから押せる(`VOTE_SKIP_DELAY`)。押すと投票していない人がいても発表(投票なし)。
     - 画面には出さないが、2分たったら自動で発表(`VOTE_TIMEOUT`。ルーム主がいなくなったときの安全策)。
     - ボットは数秒(1〜4秒)で1回だけ投票する。このラウンドで嘘のスタンプを送った人を選びやすく、自分に嘘を送ってきた人は2倍あやしい。ときどきでたらめ。
  3. 票が飛ぶ(1秒): 「ドン!」で、投票した人から選んだ人へ、その人の色の矢印が一斉に飛ぶ。票を集めた人の頭の上に、票の数だけ指マーク。矢印と指マークは、手下の発表のあとも「次へ」を押すまで消さない(だれがだれに入れたか見えるように)。
  4. ため(0.5秒): 画面を少し暗くしてドラムロール。
  5. 発表(1秒): 手下だった人にスポットライト。名札を紫に「手下」。「ジャジャーン!」。手下はニヤッと笑う顔。「手下!」の札(投票した全員が入れた手下は放心顔で「バレバレ!」、1票も入らなかった手下は「だましきった!」)。(票を集めたのに手下ではなかった人の「ちがうよ!」は、画面がごちゃごちゃするのでやめた)
  6. 点数(0.5秒): 手下に投票した人に「+1」(`SCORE_VOTE_CORRECT`)。1票も入らなかった手下に「+1 だましきった!」(`SCORE_MINION_FOOLED`)。
  7. 発表のあとは、手下が出た画面のまま待つ(自動では進まない。前は自動で進めていたが、すぐ画面が変わってしまうのでやめた)。ルーム主(ひとりのときは自分)には下に「次へ ▶」、ほかの人には「ルーム主が「次へ」を押すのを待っています」。押すと次のラウンド、最後のラウンドなら試合の結果ページ(`GameState.can_go_next`)。
- 手下が2人でも、選ぶのは1人だけ。どちらかに当たれば +1。「バレバレ!」「だましきった!」は手下ごとに決める。
- 発表の演出は `scripts/view/vote_reveal.gd`。みんなの画面で同じ流れ。
- だれが投票したかは届くが、だれに入れたかは発表まで届かない。投票する人の数はホストから届く(参加者は手下がだれか知らないので)。
- **まだ作っていない**: ルーム主が抜けたときに別の人へルーム主を引き継ぐ(今の作りでは、ルーム主が抜けると参加者に「通信が切れました」と出る)。

## 停電イベント(見た目だけ。ルールは変わらない)
- 1試合に1回、2〜4ラウンド目のどれか(ランダム)で、ラウンドの途中(鬼が0.25〜0.8周歩いたところ)にとつぜん停電する。
- 停電の瞬間に「ブツッ」と鳴り、「停電!」と出る。停電してから鬼が1周したら「パッ」と電気がつく(その前に拾って追いかけっこが始まったら、そこでつく。勝敗が出たときも。GameConfig.BLACKOUT_LAPS)。
- 停電中は画面がとても暗くなる(真っ黒ではない。明るさ3%)。**落とし物はだれの画面にも映らない**(稲光のときも。落とした鬼だけは見える)ので、停電中は誰の後ろに落ちたか、みんなわからなくなる。キャラの目だけがうっすら光り、ときどき窓の外の稲光で一瞬だけ見える。自分が鬼なら、懐中電灯で自分のまわりがうっすら見える(鬼の画面だけ)。名札・スタンプの吹き出し・ボタンなどの表示は暗くならない。
- 停電中は、ボットはスタンプを送らない(だれの後ろも見えないので。人は送れる)。
- 暗くするのは、3D の塗りそのもの(Toon のシェーダーのグローバル dark_bright など)と空の色。画面全体に暗い幕を重ねる方法は、描く量が増えて弱い GPU で 60→40 コマに落ちたのでやめた。
- 暗さ・稲光の間かく・懐中電灯の大きさは GameConfig(BLACKOUT_*)で変えられる。⚙メニューの「次のラウンドを停電にする(開発用)」(キーボードは G)で試せる。

## 入力・ボタンの絵
- ブラウザ版で名前・スタンプの言葉・カラーコードを入れるときは、ゲームの画面の上に HTML の入力の窓を重ねる(WebInput)。ブラウザの入力ダイアログ(prompt)は出ている間ページを止めて音も止まるので使わない。
- 「落とす」「フェイク」のボタンの絵は、そのラウンドの落とし物(教室: ハンカチ・上履き・ランドセル・机・教卓/海辺: 貝殻・ビーチボール・浮き輪・砂の城・バナナボート)。フェイクはうすい絵と点線のふち。
- 牛乳・水鉄砲の相手は、キャラだけでなく足もとの青い丸をタップしても選べる。

## きせかえ(ロビーの「きせかえ ▶」。名前・体の色・小物をまとめて変える。見た目だけ)
- ロビーには自分の色の丸と名前だけ出し、変えるのは「きせかえ」の画面(上に名前と体の色、左に見本のキャラ、右に小物)。
- 帽子(キャップ・ニット帽・シルクハット)・メガネ(丸・四角)・リボン・豚の鼻。全部同時につけられ、それぞれ9色から選べる。
- 選ぶ画面では、自分の体の色の見本のキャラが、選んだ小物をつけてゆっくり左右を向く。この端末に保存し、オンラインでは名前・色と一緒にホストに送って、みんなの画面に出る。
- 鬼になったときは鬼の帽子(黄色い帽子・麦わら帽子)をかぶり、小物の帽子は隠れる(メガネ・リボン・鼻はそのまま)。ボットは小物なし。

## 振り向く瞬間の演出(見た目と音だけ。判定・立ち上がり・追いかけっこの開始は遅らせない)
- **タメ**:「振り向く」を押した瞬間、自分の画面に「ザッ…」の音と集中線(0.3秒)。振り向く動き(頭→上半身)がそのままタメになる。
- **当たり**:自分の画面の上のほうに「あったー!!」(0.5秒)と短いファンファーレ。すぐ追いかけっこ(操作の案内も上のほうに小さく)。ほかの人の画面では、その人の頭の上に「あったー!!」と、その場所からファンファーレ。
- **ハズレ(お手つき)**:「ガーン!」の音と文字。本人の画面は、まずカメラが自分の顔の正面に寄って放心の顔を大きく映し(0.6秒)、そのまま崩れ落ちるところを少し引いて見せてから、上からの眺めになる(顔のアップの間は、背もたれが顔にかぶらないように自分の椅子を隠す)。キャラはひざから崩れ落ちて(ひざをつき、背中を丸めて頭をたれる)から、とぼとぼ真ん中まで歩いて体育座り(放心の顔。みんなの画面で見える)。本人の画面は少しゆれる(⚙メニューの「画面のゆれ」でオフにできる)。
- 文字は翻訳ファイルで管理(あったー!! / ガーン!)。

## 見逃しの演出(鬼が1周しても、落とされた人が気づかなかった。タップでとばせる)
1. 鬼が後ろから肩を「トントン」(音と文字)。鬼は気づかなかった人の方を向く。
2. 気づかなかった人が立ち上がり、**体ごと**くるっと鬼の方へ振り向く(少し後ろ=鬼の側へ出ながら。頭だけひねると、鬼の側から見て後頭部に顔があるように見えたので変えた)。本人の画面もゆっくり後ろを向く。顔のアップの間は、見ている本人(鬼か気づかなかった人)の体は映さない(近くで向かい合うので、カメラの前をさえぎらないように)。
3. 振り向いた瞬間の顔のアップ(`MISSED_FACE_TIME`): **鬼の画面には相手のガーン!の顔**(あごが外れたような顔: 白目に小さな黒目・縦に長くガクッと開く口・おでこの青い縦線(顔の半分=正面から見て左側だけ。いちばん左が長く、右へ行くほど短い。全体に並べると前髪に見えたので)・汗。CharacterModel.SHOCK)、**気づかなかった人の画面には鬼のニヤニヤ顔**(細めた目・片方が上がった口・つり眉)、**ほかの人の画面には2人を横から**。
4. 放心の顔(×の目)になり、頭から魂(白いおばけの形)がふわっと抜ける。間の抜けたラッパの「チーン」(みんな2人を横から見る)。
5. 落とし物を頭にのせたまま、とぼとぼ真ん中へ歩いて体育座り(頭の落とし物は次のラウンドで消える)。歩き出すと見出しが出て、そのあと投票。
- みんなの画面で同じ流れ(顔のアップだけ、鬼と気づかなかった人の画面がちがう)。どこでもタップでとばせる。演出のぶん、投票の時間を6秒のばす(`MISSED_SCENE_TIME`。演出の合計より長くする。テストで確かめている)。
- 答え合わせのリプレイ(「そのとき後ろでは…」: 足取り・ほんと/ウソのハンコ・ウソつきにスポットライトなど)は一度作ったが、やめた(依頼者の判断)。
- 手下のカードをめくると、手下が気づかなかった人に送ったウソのスタンプに「ウソ: ○○」の印。

## 座っている人ができること
- **振り向く**:1ラウンドに **2回まで**。後ろに落ちていれば、振り向いた瞬間にそのまま拾って追いかける(「拾う」ボタンはない)。使い切ると、本当に落とされても拾えない。
  - 後ろに何もないのに振り向く(**お手つき**)と、その人は**輪から抜けて、真ん中で体育座り**する(そのラウンドの間)。減点はしないが、**そのラウンドの点は0点**(そのラウンドで先に取った点もなくなる。ほかのラウンドの点は残る)。外れの回数は、表情の変化と、だました人(手下・鬼)の点数にも使う。
  - 抜けた人の椅子は空席のまま残る。鬼はそこでは止まらず、落とせない。次のラウンドで、もとの席に戻る。
  - 抜けた人の画面は、輪の上から見下ろす眺め(輪の全員と、スタンプやバナナを送る相手が見分けられる近さ)になり、**全員の後ろが見える**。**だれにでもスタンプを送れる**(両どなりにも)が、点にはならない。追いかけっこ中は**バナナも投げられる**。振り向きはできない。
  - 座っている人が全員お手つきで抜けたら、鬼の勝ち(負けた人はいない。次のラウンドも同じ鬼)。
  - 外れたら抜けるので、振り向きの2回目を使う場面は、実際にはほぼない(回数のルールは残してある)。
  - 「振り向く」ボタンは、まん中に回る矢印(↻)と「振り向く」の文字(数字のバッジはない)。0回になるとボタン全体が灰色になって押せない。押している間だけ振り向き、そのあいだボタンが沈む。
  - 振り向いた姿は全員に見える。
  - 追いかけっこ中と勝敗が出たあとは、回数を気にせず振り向いて見物できる。
- **スタンプ**:記号ではなく**言葉**。3種類(言葉は scripts/core/texts.gd にまとめてあり、あとで翻訳できる)。
  - 落ちてる😨(「見ろ」)/平気👍(「見るな」)/信じて🥺(「見ろ」)。「ニセかも」はなくした。
  - 絵文字は、どの端末でも同じ見た目になるように、Noto Color Emoji(OFL)から3つだけを切り出したフォントをゲームに入れている。
  - **言葉はシャッフル**:意味(絵文字)ごとに4つの言葉のセットがあり(😨 落ちてる/うしろ!うしろ!/来てるよ!/あるある!、👍 平気/セーフ!/まだまだ/なんもないよ、🥺 信じて/マジだって!/ぜったいホント/うそじゃない。英語版もある)、試合が始まるたびに、プレイヤーごとに1つずつランダムに選ぶ(ボットも)。試合の途中では変えない。ロビーに今の3つの言葉と「シャッフル」ボタン(押すとその場で引き直す。何度でも)。ロビーに出ている言葉が次の試合で使われ、試合が始まると次の試合の言葉を引いておく。言葉は番号で届くので、受け取った人の画面では、その人の言語のセットの同じ番号の言葉が出る(Texts.STAMP_SETS)。送るボタンと届いた吹き出しの両方に、その試合の言葉。
  - **自作の言葉**:きせかえの画面の「スタンプの言葉を自分で作る」で、3つの言葉を好きな言葉に(6文字まで)。自作の言葉を入れた人は、試合が始まっても自動ではシャッフルされない(ロビーの「シャッフル」を押すとシャッフルに戻る)。悪口や個人情報(3けた以上の数字・メール・URL・住所など)は自動のチェックで使えない(scripts/core/word_filter.gd)。「ほかの人の自作の言葉: 表示しない」にすると、自作の言葉のかわりに同じ意味のシャッフルの言葉が出る。言語がちがう人の自作の言葉も、受け取った人の言語のシャッフルの言葉で出す。変えた言葉は端末に保存し、オンラインではホストに送られ、ホストがもう一度チェックしてから全員に配る。
  - 送り方:人(か名札)をタップすると、その人の足もとが黄色く光り、頭の上に「送る相手 ▼」の印が出る。画面の下のまん中に「◯◯に送る」と、3つの言葉のボタン(大きめ・3つとも白地)が横に並ぶ。押したら送って閉じる。ほかの場所をタップしても閉じる(ほかの人をタップすると、その人に選び直し)。鬼のときは、鬼のボタンに重ならないよう少し上に出る。
  - 押したときに短い効果音が鳴る(言葉ではない声。仮の音)。
  - スタンプは種類で届き、受け取った人の言語で出す(上の「言語」)。
  - **送り主が出る**:届いたスタンプは、送った人の体の色の吹き出しに「名前:言葉」(自分は「あなた」、鬼は「鬼」)。
  - **1人に同時に3つまで**届く(早い者勝ち)。1つ1つ、**鬼が半周歩いたら消え**、空いた枠に次が届く。
  - 枠がいっぱいで届かなかったときは、その相手への1回は使わない(あとでまた送れる)。送れる数に上限はないが、**同じ相手には1ラウンド1回**。
  - **6人まで(5席まで)は、届いたスタンプの送り主は「だれか」**(`STAMP_ANON_MAX_SEATS`)(灰色の吹き出し。正面の人の後ろしか見えないので。鬼のスタンプは「鬼」、自分が送ったものは「あなた」。見逃しの答え合わせでは名前を出す)。
  - **8人のときは、両どなりには送れない**(手下も同じ)。送れない相手(両どなり・このラウンド送った人)は名札が薄く、タップしても反応しない。
  - **5人のときは、両どなりにも送れる**(ただし後ろは見えないので、当てずっぽうになる)。
  - **鬼もスタンプを送れる**。お手つきで抜けた人は、だれにでも送れる。
  - 自分あての吹き出しは、左下に届いた順に3つまで積み重なり、届いた瞬間に画面のふちが光る。ほかの人あては、その人の名札の上に積む。牛乳で前が白いときも、吹き出しは牛乳の上に出る(名札は隠れる)。
- **バナナの皮**:追いかけっこ中だけ、何回でも投げられる(お手つきで抜けた人も。ボットは追いかけっこ1回につき1回まで)。鬼か追いかける人のどちらかを選んで、その人の3m前の、いま走っている列に落とす。低い障害物になる(左右に動けばよけられる。踏むと転んで、皮は消える)。

## 鬼ができること(人が鬼のとき)
- スティックを倒さなければ、自動で前に歩く。歩く向きに倒すと速く歩く。反対に倒すと止まり、倒し続けると後ろに戻れる(いちばん進んだ地点から2m=3歩分まで)。「止まる」ボタンはない。
- **落とす**:いちばん近い席の後ろに落とす(1ラウンド1回)。4周しても落とさないと、自動で落ちる。
- **フェイク**(前の名前は「落とす音」):落とさずに、本物とまったく同じ置く音だけ出す(何回でも)。近くのボットがときどきだまされて振り向く。
- 鬼が出せる音は「フェイク」だけ(声はなくした)。
- 鬼のボタン(右下):落とす(いちばん右・オレンジ・赤い水玉のハンカチの絵)、その左に牛乳とフェイク(点線のハンカチと音の波の絵)を縦に2つ。

## 追いかけっこ
- 鬼は輪の外側を**2周**して空いた席に座れたら勝ち。それまでに1m以内に近づいてタッチできたら、追いかけた人の勝ち(周回数は GameConfig.CHASE_LAPS で変えられる)。タッチは**周回も数えて**、追う人が鬼のすぐ後ろまで追いついたときだけ(ほぼ1周遅れで気づいた人に、鬼が後ろから近づいて体が重なってもタッチにならない)。
- 鬼も追いかける人も、**同じ速さ**(秒速3.2m)で、自動で同じ向きに走る。逆走と待ちぶせはできない。
- 追いかけっこが始まると、**鬼も追う人も内側の列から走り出す**(スティックを倒すまで内側へ寄る)。
- コースは**3つの列**(内・まん中・外)。内側の列ほど近道だが、効きは弱めてある(内側はまん中より約6%速く回れるだけ。試遊で「追う人が速すぎて鬼がすぐ捕まる」とわかったため。GameConfig.LANE_SHORTCUT)。
- 操作:走るのは自動。**スティックを左右に倒す**と、倒している間だけ内側・外側へなめらかに動く(ジョイスティックの感覚。ジャンプはない)。パソコンは A/D(←/→)か、画面のスティックをマウスでドラッグ。画面の右が輪の外側か内側かはカメラの向きに合わせてある。
- カメラは、走る人のすぐ後ろ・少し上から、走る先を見る(走る向きが画面の奥)。
- コースには**障害物**:後ろに寄せたバケツ(低い)・椅子と机(高い)を置く。数(4〜7個)・場所・列・種類は毎回ランダム(近すぎないように2.2m以上あけ、走りはじめた2人のすぐ前には置かない)。座っている人と体育座りの人が投げたバナナも障害物になる。
  - どの障害物も、左右に動いてよける(試遊で「逃げ方がわかりにくい」とわかったので、ジャンプとスワイプはやめてスティックだけにした)。
  - ぶつかると転んで、少しの間(1秒)止まる。鬼も追いかける人も同じ。重い物を持っている人は起き上がるまでが長い。
- 同じ速さなので、勝ち負けを分けるのは「近道の内側を走れるか」と「障害物で転ばないか」。

## 点数(1試合の合計で順位)
| できごと | 点 |
|---|---|
| 鬼が空いた席に座れた | 鬼 +3 |
| 鬼にタッチした | 追いかけた人 +3 |
| 負け(座られた・タッチされた・気づかなかった) | 負けた人 −3、次の鬼 |
| お手つき(1回でも) | そのラウンドの点は0点(減点はなし)。輪から抜ける |
| 鬼が勝った(席に座れた・最後まで気づかれなかった・全員お手つき) | 手下 +2(手下が負けた本人のときや、お手つきで抜けたときはなし) |
| スタンプで教えた・だました(鬼が相手の後ろを通ってから10秒以内に送ったものだけ) | 下の表 |

スタンプの「教えた」「だました」は、次のとおり。相手の動きは、そのスタンプが表示されている間(鬼が半周するまで)で判定する。

| 送ったスタンプ | 本当は | 相手の動き | 判定 |
|---|---|---|---|
| 落ちてる/信じて | 落ちていた | 振り向いた | 教えた |
| 落ちてる/信じて | 落ちていない | 振り向いて外れ | だました |
| まだへいき | 落ちていない | 振り向かなかった | 教えた |
| まだへいき | 落ちていた | 振り向かなかった | だました |

点数は、送った人の役で変わる。

| 送った人 | 正しく教えた | だました |
|---|---|---|
| 普通の人 | +1 | 0 |
| 手下 | 0 | +1 |
| 鬼 | 0 | +1 |

- 点が入ったお知らせは、送った本人にだけ出る(手下がばれないように)。

## 見え方と手がかり(後ろが見えない仕組み)
- 自分の画面には輪の内側しか映らない。
- **両どなり**の人の姿は見えるが、その後ろに落ちた物は自分の画面には映らない(手下だけは見える)。
- **向かい側**(両どなり以外)の人の後ろは見える。ただし、小さいハンカチは人や椅子の陰で見えにくく、大きい物は見える。
- 背後の手がかりは次の3つ。
  - **足音**(鬼のいる方向から聞こえる)
  - **置く音**(重い物ほど大きい)
  - **鬼の影**(鬼が後ろ3m以内に来ると、自分の前の床に人の形の影(胴と頭、ふちはぼんやり)がのびる。近いほど濃く長い。鬼のいる左右に合わせて少しななめ。止まれば影も止まる)

## ボットの今の動き
- 性格は4つあり、名前の横に出る。正直さは役で決まるので、性格はそれ以外を変える。
  - せっかち:早く気づく。スタンプ1つで振り向きやすい。
  - 慎重:気づくのが遅い。「見ろ」が2つ以上そろわないと振り向かない。スタンプを送るのも少なめ。
  - うたがい屋:スタンプをあまり信じない。
  - おしゃべり:スタンプをたくさん送る。
- 後ろに落とされたことを最初から知っていて、10〜46秒のどこかでランダムに拾う(鬼の1周は約50秒。1.5〜55秒だったが、スタンプの助けを減らしたら見逃しが増えたので1.5〜40秒にしたところ、早く気づきすぎてすぐ捕まるようになったので、いちばん早くても10秒後にした。平均は約28秒で、最初と同じくらい)(重い物ほど早い、牛乳がかかっていると遅い、性格で変わる)。手がかり(止まった・音・影)とは関係なく動いている。
- スタンプは、鬼が10秒以内に後ろを通った人のうち、表示中のスタンプが少ない人に送る(落とされた人だけに集まらないように)。
  - 普通のボット:見える相手にはだいたい本当(9割)。5人のときの両どなりには当てずっぽう。
  - 手下のボット:ウソは鬼の役に立つときに絞る。後ろに何もない人には、ふだんは本当のことを言う(ウソは2割)。落とされた人には「平気」とウソをつきやすい(6割5分)。(前は7割ウソで、試遊で「手下のボットがわかりやすすぎる」とわかったので変えた)
  - 鬼のボット:ときどきスタンプを送る。だいたい嘘(7割)。
- スタンプを受け取ったボットは、表示中のスタンプの多数決(「見ろ」+1、「まだへいき」−1)で振り向くかを決める。前のラウンドの手下と、鬼が送ったスタンプは、0.3票として数える(鬼はだいたい嘘なので)。票がそろっても、実際に振り向くのは60%(性格で変わる)。人の鬼のフェイクにだまされるのは20%。(試遊で「ボットのお手つきが少し多い」とわかったので、信じる確率を70→60%、フェイクを30→20%に下げ、鬼のスタンプの重さを下げた)振り向ける回数が残り1回のときは、もっと票がそろわないと振り向かない。
- 鬼の「フェイク」にも、ときどきだまされる。
- お手つきで抜けたボットは、全員の後ろが見えるので、スタンプとバナナだけを使う。
- ボットの鬼も、だいたい1ラウンドに1回牛乳を使う(半分は、落とす瞬間に落とす相手にかける)。
- ボットは、鬼が自分の後ろを一度も通っていないうちは振り向かない。鬼が後ろを通ってから5秒たつまでも振り向かない(気づいたとき・落とす音・スタンプのどれでも)。置いた瞬間に振り向かれると、逃げる鬼にバナナを置く間がなくなるため。5秒より前に届いたスタンプは、5秒たったところで考え直す。
- 追いかけっこ(鬼も追いかける人も):ふだんは内側の列を走る。前の障害物を見て、列を変えてよける。ただし4回に1回くらいは気づかずにぶつかる。追いかける人は、鬼のすぐ後ろまで来ると鬼と同じ列に入る。座っている(抜けた)ボットは、ときどきバナナを投げる。
- ボットの鬼は、決まった速さで歩いて、ランダムな相手にランダムなタイミングで落とす。

## 試遊でわかったこと(家族で遊んだ結果と、それで変えたこと)
- 毎回つい振り向いてしまう → 振り向きは2回まで、がまんの +1点、鬼の影を追加した。→ 試遊のあと、お手つきの減点とがまんの +1点はなくし、「回数制限だけ」にした。→ さらに、お手つき1回で輪から抜けて、そのラウンド0点にした(抜けた人は真ん中で見物しながらスタンプとバナナで参加できる)。
- 音で落とした場所がすぐわかる → ハンカチの音は小さく。鬼は毎回止まる。声で音をかき消せる。→ その後、声はなくして、牛乳(画面を白くする)に変えた。
- スタンプが全部嘘になりそう → 教えた得とだました得を同じ +1 にした。点数になるのは鬼が通った直後だけにした。
- 両どなりが丸見えだった → 人は見えるが、後ろの物は見えないようにした。
- **いちばんの課題:歩く人の動きとスタンプのやり取りが速すぎて、考える暇がない** → 鬼の速さを 1.6 → 1.0 → 0.7 m/秒にし、止まる時間を1.5秒、スタンプ表示を5秒にした(まだ効果は試していない)。いまのスタンプは、鬼が半周するまで表示される。
- 子どもは「もっと人数が多いほうがいい」 → 8人にした(5人も選べる)。
- ボットの動きがイマイチ → 性格を付け、スタンプの多数決で振り向くようにした(まだ試していない)。
- 自分に落ちたかどうかが勘になる → 鬼の手下、送り主の表示、1人に3つまで、同じ相手に1回、8人のときは両どなりに送れない、を入れた(まだ試していない)。

- 動き:骨組みと動きは CC0 素材(Quaternius「Universal Animation Library」)。座る(少し揺れる)・立ち上がる・歩く・走る・座り直す。振り向きは頭→上半身の順に少し遅れて回る。バナナで転ぶと、物理演算でぐにゃっと倒れて(約0.7秒)、元の動きに戻って起き上がる(約0.35秒)。

- 撮影モード(開発用。Steam のカプセル画像・スクリーンショット・紹介動画の素材づくり):⚙メニューの「撮影モード(開発用)」(キーボードは P)。ひとりで遊ぶときだけ開ける(開いている間ゲームは止まる。オンラインでは、ほかの人のゲームも止まるので開けない)。ゲームの状態にはさわらず、撮影用の状態(8人)と教室を `scripts/view/photo_studio.gd` の中で別に作る(WorldView をもう1つ作り、毎フレームの更新はしないで、ポーズと表情だけ撮影モードが決める)。開いている間は、ゲームの画面・HUD・ボタン(中の CanvasLayer も)を隠す。本番では GameConfig.SHOW_PHOTO_MODE を false にして隠す。
  - **使い方**(右の操作パネル):
    - 場面: 教室 / 海辺。
    - カメラ: **輪の全体**(少し上から輪と全員)/ **教室の全体**(黒板・窓・カーテン・机が入る引きの画。海辺は海と空)/ **キャラの寄り**(選んだキャラの上半身。顔の正面から)/ **鬼の後ろ**(鬼の背中越しに輪を見る)/ **自由**(PC: 左ドラッグで回す・ホイールで近づく。スマホ: 1本指で回す・2本指のピンチで近づく。今のカメラの位置から始まる。キャラの寄りから切りかえると、そのキャラのまわりを回る)。天井より高いところから見るときは天井を映さない。
    - キャラ: ◀ ▶ で選ぶ(自分・ボット・鬼)。「全員に」で、選んだキャラのポーズと表情を全員に。
    - ポーズ(選んだキャラ): 座る / 体育座り / 立つ / 歩く / 走る / 振り向く / 転ぶ / ひざ崩れ。立つ・歩く・走る・転ぶ・ひざ崩れは、椅子と重ならないように輪の外側(鬼が歩くところ)に立つ(歩く・走る・転ぶは輪にそって進む向き、立つ・ひざ崩れは輪の中心を向く)。海辺の「座る」は体育座り。
    - 表情(選んだキャラ): ふつう / 驚く / ガーン / 勝ち / 負け / ニヤニヤ / 気まずい / お手つき / 必死 / 困り眉 / 汗だく / 放心。
    - 落とし物: なし / 手に持つ(選んだキャラ。走らせるとそのまま持って走る)/ 背中の後ろ(選んだキャラの席の後ろの床)。「種類 ▶」で落とし物を変える(ハンカチ→上履き→…、海辺は貝殻→…)。
    - 背景: ふつう / キャラだけ(教室・椅子・影を消す。画面では灰色の背景で見せ、保存すると背景が透明の PNG。ロゴやカプセル画像の切り抜き用)。
    - 動き: うごく / 止める(まばたき・ゆれを止めて、決めた形で撮る)。
    - **UIを消す(H)**: 操作パネルを隠す。PC は H キーでも出す/隠すを切りかえ(Esc でも戻る)。スマホは画面を軽くタップすると戻る(ドラッグは自由カメラの操作)。
    - **4Kで保存**: 画面の大きさに関係なく、今のカメラで 3840×2160 の PNG を作る(別の画面に描くので、操作パネルは写らない)。Web 版はダウンロードになり、PC は「ピクチャ」フォルダ(なければ Godot のユーザーデータのフォルダ)に `ushiro_日時.png`(キャラだけのときは `_alpha` つき)で保存。パネルの下に保存先が出る。
  - **ボットの名前を変える(宣伝用の動画のため。開発用で、販売版には入れない)**: ロビーの「きせかえ」→「ボットの名前(宣伝用) ▶」。ボット1〜9の名前を入れる(PC はその場で入力、Web 版は入力の窓)。空のボットはふつうの「ボット1」など。「全部ふつうの名前にもどす」で消せる。端末に保存し(`Profile.bot_names`)、次に始める試合(ひとり・部屋を作る)と撮影モードで使う(`GameState.custom_bot_names`)。名前が変わるだけで、性格と動きはふつうのボットと同じ(性格の札は出ない)。GameConfig.SHOW_PHOTO_MODE が false なら、ボタンも出ず、保存した名前も使わない。
  - **遊んでいる画面の UI を全部消す**(スクリーンショット・紹介動画用): 遊んでいる間に H キー(スマホは⚙メニューの「UIを全部消す(撮影用・長押しで戻る)」)。ボタン・スタンプ・ラウンド表示・名札・ジョイスティック・⚙など全部が消え、ゲームはそのまま進む(PC はキーボードで遊べる)。もう一度 H、スマホは画面を0.8秒長押しで戻る。見た目だけで、ほかの人の画面には関係ない。

## 作りの制約(提案するときに気にしてほしいこと)
- Godot 4(GDScript)で作っていて、スマホのブラウザで動かす。操作はタップとボタンとスティックだけ。
- ルールは「ゲームの状態」にまとまっていて、ホストだけが動かす。新しいルールは、状態+命令+お知らせ(イベント)として足す。
- ホストは、参加者1人ずつに、その人が知ってよい状態とお知らせだけを送る(手下がだれか、など)。
- 見た目は仮の図形(カプセルの体・点の目)。凝った絵や演出は後回し。
- ボイスチャット・公開マッチング・課金はやらない。
