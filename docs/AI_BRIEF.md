# 「うしろ見ちゃダメ!」ゲームデザイン相談用まとめ(AI に渡す用)

## お願い
家族・友だち向けのオンライン「ハンカチ落とし」ゲームを試作しています。
下のルールと試遊の結果をもとに、**ゲーム性をもっと面白くするアイデア**と、**今の問題点の直し方**を提案してください。
提案するときは、次の3つも一緒に書いてください。
- 子ども(小学生くらい)にもわかるか
- スマホの小さい画面で操作できるか
- 今のルールのどれを変えるか

## ゲームの核
- 「自分の後ろだけが見えない」ハンカチ落とし。周りの人には、誰の後ろに落ちたかが見えている。
- 周りの人はスタンプで**本当を教える**ことも、**嘘でだます**こともできる。反射神経のゲームを、心理戦・読み合いにしたい。
- 1試合5〜10分。友だちや家族で何試合も遊ぶ。言葉が通じなくても遊べるのが目標(スタンプは顔・記号・音)。

## 遊ぶ形
- スマホのブラウザで遊ぶ(横向き)。人数は **8人(席7つ+鬼1人)** か **5人(席4つ+鬼1人)** を選べる。足りない席はボットが座る。
- オンライン:ホストが部屋を作り、4桁の合言葉でほかの人が入る。ホストのスマホがルールを動かす。
- オンラインでは鬼は人だけがやる。ボットが負けたときは、座っている人の中から次の鬼を選ぶ。
- ひとり(ボット相手)でも遊べる。

## 1ラウンドの流れ
1. 全員が輪になって内側を向いて座る。鬼が輪の外側を歩く。
2. 鬼は、席の後ろを通るたびに1.5秒立ち止まる。毎回止まるので、止まっただけでは落としたかどうかわからない。
3. 鬼が誰かの後ろにハンカチ(落とし物)を落とす。
4. 落とされた人が気づいて「拾う」と、立ち上がって鬼を追いかける。
5. 次のどれかでラウンドが終わる。
   - 鬼が空いた席に座れたら、鬼の勝ち。
   - 鬼にタッチできたら、追いかけた人の勝ち。
   - 鬼がもう一周して戻ってくるまで気づかなかったら、気づかなかった人の負け。
6. 負けた人が次の鬼になる。

## 1試合=5ラウンド、落とし物がだんだん重くなる
- 落とし物は、ハンカチ → 上履き → ランドセル → 机 → 教卓 の順。
- 重いほど、次のようになる。
  - 置く音が大きく、低く、遠くまで聞こえる(ばれやすい)。
  - 拾って走る人が遅くなる(教卓で約7割)。
  - 落とすまで鬼も少し遅くなる(教卓で約8割)。
  - 大きい物は頭の上にかついで走る(見た目で笑える)。

## 座っている人ができること
- **振り向く**:1ラウンドに **2回まで**。「拾う」も1回使う。使い切ると、本当に落とされても拾えない。
  - 後ろに何もないのに振り向くと「お手つき」で −1点。
  - 振り向いた姿は全員に見える。
  - 追いかけっこ中と勝敗が出たあとは、回数を気にせず振り向いて見物できる。
- **拾う**:後ろにあれば拾って追いかける(ボタン1つで振り向いて拾う)。
- **スタンプ**:人をタップして送る。回数制限なし。
  - 種類は「落ちてる!」「いま!」「信じて!」(=見ろ、の意味)と「まだ平気」(=見るな)。
  - 届いたスタンプは5秒表示され、その間はほかのスタンプは届かない(早い者勝ち)。
  - 誰が送ったかは表示しない。
  - 自分あてのスタンプは画面の下に色付きの吹き出しで出て、画面のふちも光る。
- **バナナの皮**:追いかけっこ中だけ、1ラウンド1個。鬼か追いかける人のどちらかを選んで、その人の2.5m前の通り道に落とす。踏むと1秒転ぶ。曲がればよけられる。

## 鬼ができること(人が鬼のとき)
- 自動で歩く。スティックで速く・ゆっくりできる。「止まる」で立ち止まる。
- **落とす**:いちばん近い席の後ろに落とす(1ラウンド1回)。4周しても落とさないと、自動で落ちる。
- **落とす音**:落とさずに、本物とまったく同じ置く音だけ出す(何回でも)。近くのボットがときどきだまされて振り向く。
- **声**:咳/口笛/手拍子/叫ぶ。声を出してから0.8秒以内に落とすと、置く音がかき消されて小さくなる。声は1.5秒に1回まで。
- 気づかれたら自動で走り、内側/外側にハンドルを切る。

## 追いかけっこ
- 追う人も鬼も、自動で同じ向き(輪を回る向き)に走る。操作は内側/外側に寄るだけ。逆走と待ちぶせはできない(待ちぶせで必ず勝ててしまったため)。
- 内側を走るほど近道。追う人のほうが少し速い(秒速3.3m、鬼は3.0m。重い物を持つと遅くなる)。
- 1m以内に近づいたらタッチ。

## 点数(1試合の合計で順位)
| できごと | 点 |
|---|---|
| 鬼が空いた席に座れた | 鬼 +3 |
| 鬼にタッチした | 追いかけた人 +3 |
| 負け(座られた・タッチされた・気づかなかった) | 負けた人 −3、次の鬼 |
| お手つき | −1 |
| がまん:一度も振り向かなかった。ただし、見える所にハンカチが落ちていないときに、鬼が自分の後ろを通ったことが1回以上ある | +1(負けた人と鬼はのぞく) |
| スタンプで教えた・だました(鬼が相手の後ろを通ってから10秒以内に送ったものだけ) | +1(下の表) |

| 送ったスタンプ | 本当は | 相手の動き(スタンプ表示中の5秒) | 送った人 |
|---|---|---|---|
| 落ちてる!/いま!/信じて! | 落ちていた | 振り向いた | +1(教えた) |
| 落ちてる!/いま!/信じて! | 落ちていない | 振り向いてお手つき | +1(だました) |
| まだ平気 | 落ちていない | 振り向かなかった | +1(教えた) |
| まだ平気 | 落ちていた | 振り向かなかった | +1(だました) |

## 見え方と手がかり(後ろが見えない仕組み)
- 自分の画面には輪の内側しか映らない。
- **両どなり**の人の姿は見えるが、その後ろに落ちた物は自分の画面には映らない。
- **向かい側**(両どなり以外)の人の後ろは見える。ただし、小さいハンカチは人や椅子の陰で見えにくく、大きい物は見える。
- 背後の手がかりは次の3つ。
  - **足音**(鬼のいる方向から聞こえる)
  - **置く音**(重い物ほど大きい。声でかき消されることがある)
  - **鬼の影**(鬼が後ろ3m以内に来ると、自分の前の床に影が映る。近いほど濃い。止まれば影も止まる)
- 顔:お手つきするたびに顔が崩れる(困り眉 → 汗・ちぐはぐな目 → 3回目から放心顔)。全員から見えるので、焦っている人がわかる。

## ボットの今の動き(「イマイチ」と言われている)
- 後ろに落とされたことを最初から知っていて、1.5〜55秒のどこかでランダムに拾う(重い物ほど早い、声でかき消されると遅い)。手がかり(止まった・音・影)とは関係なく動いている。
- スタンプは、鬼が通ってから10秒以内の人にだけ、8〜18秒おきに送る。向かいの人には半分本当・半分嘘。両どなりには当てずっぽう。
- 届いた「見ろ」系のスタンプは半分の確率で信じて振り向く。鬼の声や「落とす音」にも、ときどきだまされる。
- 追いかけっこは内側を走り、鬼に近づいたら鬼のほうへ曲がる。バナナはときどき投げる。
- ボットの鬼は、決まった速さで歩いて、ランダムな相手にランダムなタイミングで落とす。

## 試遊でわかったこと(家族で遊んだ結果と、それで変えたこと)
- 毎回つい振り向いてしまう → 振り向きは2回まで、がまんの +1点、鬼の影を追加した。
- 音で落とした場所がすぐわかる → ハンカチの音は小さく。鬼は毎回止まる。声で音をかき消せる。
- スタンプが全部嘘になりそう → 教えた得とだました得を同じ +1 にした。点数になるのは鬼が通った直後だけにした。
- 両どなりが丸見えだった → 人は見えるが、後ろの物は見えないようにした。
- **いちばんの課題:歩く人の動きとスタンプのやり取りが速すぎて、考える暇がない** → 鬼の速さを 1.6 → 1.0 → 0.7 m/秒にし、止まる時間を1.5秒、スタンプ表示を5秒にした(まだ効果は試していない)。
- 子どもは「もっと人数が多いほうがいい」 → 8人にした(5人も選べる)。
- ボットの動きがイマイチ(具体的にどこかは、まだ調べ中)。

## まだ決まっていないこと・相談したいこと
1. 考える時間をどう作るか。例:鬼が止まるたびに全員が考える時間を作る、など。
2. ボットをどうすれば「人っぽく」、読み合いの相手になるか。性格を付ける、手がかりに反応する、など。
3. だます得と教える得のバランス。誰も信じなくなる/教えすぎて鬼が勝てない、のどちらにもならないようにしたい。
4. 鬼の工夫(声・落とす音・止まる・速さ)が、座っている側の読み合いと噛み合っているか。
5. 1試合の長さ(今は1周約46〜49秒、5ラウンド)。
6. 企画書にはまだ入れていない案:ニセのハンカチ(本物は1枚だけ、ニセを拾ったらお手つき)、舞台ごとの落とし物セット(海辺・お城など)。

## 作りの制約(提案するときに気にしてほしいこと)
- Godot 4(GDScript)で作っていて、スマホのブラウザで動かす。操作はタップとボタンとスティックだけ。
- ルールは「ゲームの状態」にまとまっていて、ホストだけが動かす。新しいルールは、状態+命令+お知らせ(イベント)として足す。
- 見た目は仮の図形(カプセルの体・点の目)。凝った絵や演出は後回し。
- ボイスチャット・公開マッチング・課金はやらない。
