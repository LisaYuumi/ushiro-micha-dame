# 「うしろ見ちゃダメ!」機能まとめ(英語名:Don't Look Back!)

今あるすべての機能を、コピーしてそのまま使える形にまとめたもの。くわしい作りや理由は `docs/AI_BRIEF.md`。

---

## 1. ゲームの概要
- **「自分の後ろだけが見えない」オンラインのハンカチ落とし。** まわりの人には、誰の後ろに落ちたかが見えている。
- まわりの人は言葉(スタンプ)で**本当を教える**ことも、**ウソでだます**こともできる。反射神経のゲームを、心理戦・読み合いにする。
- 毎ラウンド、ひそかに**鬼の手下**がまぎれている(ウソをついて鬼を助ける)。
- 1試合 = 5ラウンド(5〜10分)。スマホのブラウザで横向きに遊ぶ。

## 2. 遊び方のモード
- **ひとりで遊ぶ**:ボット相手。人数は 5〜10人(ロビーの「− 8人 +」で選ぶ。足りない席はボット)。
- **部屋を作る/部屋に入る**:ホストが部屋を作り、4桁の合言葉で入る。ホストのスマホがルールを動かす。
- **チュートリアル**:はじめて起動したときに「チュートリアルで遊び方を見る?」と聞く。ロビーと⚙メニューからいつでも遊べる(約1〜3分)。
- **舞台**:教室 / 海辺 / 夜の教室(ロビーで選ぶ)。
- **言語**:日本語 / 英語(端末の言語に合わせる。🌐で切りかえ)。
- **保存**:名前・体の色・小物・言葉・音量・言語・舞台・チュートリアルを終えたか、を端末に保存。

## 3. 1ラウンドの流れ
1. 全員が輪になって内側を向いて座る。鬼が輪の外側を歩く。
2. 鬼は席の後ろを通るたびに立ち止まる(止まっただけでは落としたか分からない)。
3. 鬼がだれかの後ろに落とし物を落とす。
4. 落とされた人が振り向くと、拾って立ち上がり、鬼を追いかける。
5. ラウンドの終わり方:
   - 鬼が空いた席に座れたら → 鬼の勝ち
   - 鬼にタッチできたら → 追いかけた人の勝ち
   - 鬼が一周しても気づかなかったら → 気づかなかった人の負け(「トントン…」の見逃しの演出)
6. 教室のまま、手下を当てる**投票**(→ 発表)。
7. 負けた人が次の鬼。

## 4. 役
| 役 | できること |
|---|---|
| 座っている人 | 振り向く(1ラウンド2回まで。何もないと**お手つき**で輪から抜けて真ん中で体育座り、そのラウンド0点)・言葉を送る・追いかけっこ中にバナナを投げる |
| お手つきで抜けた人 | 全員の後ろが見える。だれにでも言葉を送れる(点にはならない)。バナナも投げられる |
| 鬼 | 自動で歩く(速く・止まる・少し戻る)。落とす・フェイク(本物と同じ音だけ)・鬼の道具(1ラウンド1回)・言葉を送る |
| 鬼の手下 | 本人にだけ知らされる。両どなりを含め全員の後ろが見える(自分の後ろは見えない)。だますと点。鬼が勝つと点。8人以上だと、ときどき2人(人数は鬼だけが知る) |

## 5. 言葉(スタンプ)
- 3種類:**落ちてる😨**(見ろ)/**平気👍**(見るな)/**信じて🥺**(見ろ)。
- 言葉は試合ごとに**シャッフル**(例:😨 落ちてる/うしろ!うしろ!/来てるよ!/あるある!)。自分で作ることもできる(6文字まで。悪口などは自動で使えない)。
- 送り主の名前が出る(6人以下は「だれか」)。1人に同時に3つまで。同じ相手には1ラウンド1回。8人以上は両どなりに送れない。
- 届いた言葉は、受け取った人の言語で出る。

## 6. 鬼の道具(舞台ごと)
| 舞台 | 道具 | かけられた人 |
|---|---|---|
| 教室 | **黒板消し**「ポンポンポン」 | チョークの粉の煙で前が見えない。頭に粉のかたまり。走るときは「ゴシゴシ!」とこすって薄くする |
| 海辺 | **水鉄砲**「ピューッ!」→「バシャッ」 | 画面全体が水色にしっかりにじんで見えない(時間がたつとふっと戻る)。まわりから見ると:頭から水がしたたる・体が濡れた色・ときどきぶるぶる・頭の上に「見えない!」 |
| 夜の教室 | **カメラのフラッシュ**「パシャッ」 | 4秒まぶしく真っ白。頭のまわりに星がくるくる。名札と言葉の吹き出しも見えない |

## 7. 点数
| できごと | 点 |
|---|---|
| 鬼が空いた席に座れた | 鬼 +3 |
| 鬼にタッチした | 追いかけた人 +3 |
| 負け(座られた・タッチされた・気づかなかった) | −3(次の鬼) |
| お手つき | そのラウンドは0点 |
| 鬼が勝った | 手下 +2 |
| 言葉で教えた(ふつうの人) | +1 |
| 言葉でだました(手下・鬼) | +1 |
| 投票で手下を当てた | +1 |
| 1票も入らなかった手下(だましきった!) | +1 |

## 8. 手下を当てる投票
- 勝ち負けのあと、教室のまま、手下以外の全員(鬼も)が「あやしい人」をタップして投票(全員そろうまで入れ直せる)。
- **振り返り**:投票が始まると、まず6〜8秒の振り返り(タップで早送り)。「鬼の手下は誰?」→「さっきの場面を思い出してみよう…」で画面が少しセピア色 → カメラが落とされた人に寄って「dogのうしろに ハンカチ が落ちていた!」、届いていた言葉がポン、ポン、ポン → お手つきの人に寄って「catが振り向いたけど、何もなかった…」→ カメラが引いてセピアが戻り「あやしい人をタップして投票!」。演出の間は全員が投票しても発表に進まない。「発表へ」ボタンは右下。
- **場面の再現と証拠**:投票が始まると、全員が自分の席に戻って輪になって座り、落とされた人のうしろには落とし物がそのまま、お手つきの人は自分の席で振り返った姿勢のまま。落とされた人は、うしろの落とし物(少し大きめ)の上に「▼」がぴょこぴょこ、お手つきの人は振り返ったガーン顔のまま、頭の上(吹き出しの上)にガーン顔の丸いアイコン。ほかの人はふつうに座った姿勢。その人の頭のすぐ上に、届いていた言葉を「送った人の名前:言葉」で最大3つ縦に並べる(プレイ中と同じ見え方。見ろ系=赤・見るな系=青。落とされた人は落とされたあとの最後の3つ=振り向く直前またはラウンドが終わる直前、お手つきの人は振り向いたときに届いていた言葉。落とされる前の言葉は出さない。1つもなければ「だれも教えてくれなかった…」)。上は「鬼の手下は誰?」と「3/8人 投票済み」だけ。いつもの左上の札は隠す。本当かウソかは出さない。カメラは大事な人と吹き出しがよく見える向きに寄せる(全員が入る範囲で)。タップは投票だけ。発表(矢印)が始まったら、言葉と目印はふっと消え、矢印 → ドラムロール → スポットライトだけ。
- **点数は必要な場面だけ**:プレイ中は、1位の人の名札に小さな👑と、右上に自分の順位「3位」だけ。ラウンドの合間に、順位と点数の一覧を2〜3秒(上がった人↑・下がった人↓。タップで閉じる)。言葉を送る相手を選んでいる間だけ、名札の横に点数。プレイ中の順位はラウンドが始まったときの点数(手下がばれないように)。game_config.gd で切りかえられる。
- **画面の見やすさ**:上の帯(ラウンド・落とし物・点数・役の札)は UI 専用で、名札や吹き出しは入らない(帯のすぐ下まで押し下げる)。左右の端・右下のボタン・言葉を送るバーにも重ならない。右下の「振り向く」「落とす」などは7割の大きさで右下の角に寄せ、少し半透明(押せないときは灰色で薄く)。ボタンの上で指を離したときだけ反応する(外にずらして離すと何もしない)。
- **言葉を送るバー**:人をタップすると、画面の下に細いバー「catに送る: [落ちてる😨] [平気👍] [信じて🥺] ×」。選んだ人の足もとが光り、頭の上に「送る相手 ▼」。送る・×・ほかをタップ・3秒何もしないで閉じる。PC は 1・2・3 キー。
- **名札と吹き出し**(プレイ中も投票も):名札はキャラの足もと(半透明の黒に白い文字)、頭の上は言葉の吹き出しだけ。吹き出しの色は言葉の意味でそろえる(見ろ系=落ちてる😨・信じて🥺は赤、見るな系=平気👍は青)。画面の端からはみ出さないよう内側に収める。
- 「ドン!」で投票の矢印が一斉に飛ぶ → ドラムロール → 手下にスポットライト「ジャジャーン!」。
- 「手下!」「バレバレ!」(全員に当てられた)「だましきった!」(1票も入らなかった)。
- ルーム主の「次へ」で次のラウンドへ。

## 9. 舞台と落とし物(ラウンドごとに重くなる)
| ラウンド | 教室(Classroom) | 海辺(Beach) | 夜の教室(Night Classroom) |
|---|---|---|---|
| 1 | ハンカチ(Handkerchief) | 貝殻(Seashell) | ハンカチ(Handkerchief) |
| 2 | 上履き(Indoor shoe) | ビーチボール(Beach ball) | 懐中電灯(Flashlight):床で光る。暗い席でも見える |
| 3 | ランドセル(School bag) | 浮き輪(Swim ring) | メトロノーム(Metronome):床でカチカチ鳴り続ける |
| 4 | 机(Desk) | 砂の城(Sandcastle) | モナリザ(Mona Lisa):目がこっちを見てキラッ |
| 5 | 教卓(Teacher's desk) | バナナボート(Banana boat) | ガイコツ(Skeleton):落とすとバラバラに崩れる |

- 重いほど置く音が大きく、転んだときの起き上がりが長い。落とすまで鬼も少し遅い。
- **砂の城**:キャラの背丈くらい。前で抱えて走ると砂がこぼれて小さくなり、転ぶと「ザザーッ」と崩れて砂山に。小さいほど軽くて速い。
- **夜の教室**:窓側は月の光で明るく、廊下側の**暗い席の人の後ろは見えない**(席はラウンドごとにランダム)。

## 10. 1試合に1回のイベント
ラウンド2〜4のどこかで、舞台に合ったものから1つ。同じイベントは2試合続けて起きにくい。名前を画面に大きく出して、下にひとこと。

| イベント(英語) | 舞台 | 起きること | ひとこと |
|---|---|---|---|
| 停電!(Blackout!) | 教室 | 鬼が1周するまで、まっくら。落とし物はだれにも見えない | 鬼が1周するまで、まっくら |
| 先生の見回り!(Teacher Patrol!) | 教室・夜の教室 | 先生が来て「しーっ!」。6秒だれも言葉を送れない(鬼は動ける) | しーっ! しばらく言葉を送れない |
| いたずらっ子!(Prankster!) | 教室・海辺・夜の教室 | 送った言葉が、そのラウンドで合計3回(4人以下は2回)、勝手に逆の意味に書き換わる(同じ人は1回まで・前半と後半にばらける)。書き換えられた本人の画面だけ、いたずらっ子が飛んできて消しゴムでゴシゴシ→クレヨンでカキカキ→「にしし」と去る演出と知らせ。ほかの人には書き換えたあとの言葉が、ふつうと同じに届く。点数は本人が押した言葉で決める。書き換えられたら同じ相手にもう一度送れる | 言葉が勝手に書き換えられるかも… |
| 蜃気楼!(Mirage!) | 海辺 | 鬼が歩き出したらすぐ(落とす前)、鬼が1周するまで。本物が見えるのは鬼以外の2人(4人以下は1人)だけ。ほかの全員には、鬼が別の席のうしろを通りすぎた瞬間に、そこにニセ(本物と同じ見た目)が見える。だれが本物を見ているかは教えない。蜃気楼のあいだは画面に薄いモヤがかかる(いつからいつまでか分かる)。鬼は少し透けてゆらゆら。終わるとモヤが晴れ、ニセはすっと消えて、本物が全員に見える。ニセを信じた言葉はウソにしない | 見えているものが、本物とはかぎらない… |

いまは起こさないイベント(コードは残してある。game_config.gd の `EVENTS_OFF` から外すと戻る):カミナリ!(夜の教室)・突風!(海辺)・チャイム!(教室)・カモメ!(海辺)。これらでしか出ない称号(カミナリの目撃者・カモメにだまされた人)も出ない。

投票の発表が終わったら、そのラウンドのネタばらしを下に短く出す(「いたずらっ子のしわざ:〇〇の『平気👍』→『落ちてる😨』」/「本物が見えていたのは〇〇と△△だけ!ほかのみんなには□□のうしろに蜃気楼が見えていた」)。投票前の振り返りの言葉は、書き換えたあと・勘違いのままの言葉。

### イベントの名付け方
- **短い名詞+「!」**(停電! / いたずらっ子! / 蜃気楼!)。何が起きたか一言で分かるものにする。
- 下の**ひとこと**で「みんなに何が起きるか」を1行で説明する。
- 英語は短く感嘆符つき(Blackout! / Prankster! / Mirage!)。

## 11. 試合の終わりの演出(約30秒。同じ教室の中でカメラが動いてつなぐ)
1. **試合終了!**:照明が少し落ちて、みんなが立ち上がって表彰台のまわりへ歩いて集まる。
2. **表彰台**:3位 → 2位 → 1位の順に台に上がり、点数が0から数え上がる。1位で紙ふぶきとファンファーレ。4位からは下に名前と点数。
3. **そして…称号発表!**
4. **称号を1人ずつ**(最大3人):カメラが寄る → 名前 → ドラムロール(最後だけ長め)→ カードがくるっと回って称号 → 理由を1行。
5. **記念写真**:みんなが横に並ぶ →「はい、チーズ!」→ パシャッ。称号のバッジは頭の上、名前と順位は足もと。「新しい試合へ ▶」。
- タップ(スペースキー)で早送り。ルーム主の「スキップ ▶▶」で全員が記念写真へ。BGM は行進曲 → 記念写真で明るい曲。

### 称号の選び方
- 回数の称号は、その人が一番で、2位と同点でないときだけ。
- 優先順:珍しい → 笑える → すごい。「正直者がバカを見た賞」「名演技賞」「逆転の道連れ王」「早とちり大王」は当てはまったら最優先。
- 最後に発表する1つは、いちばん笑える称号(オチ)。
- 同じルームで続けて遊ぶとき:直近3試合の称号は、ほかに当てはまれば選ばない/同じ称号は2試合続けて出ない/同じ人に同じ称号は出にくい/出た回数が少ない称号を少し優先/少しランダム。
- 理由の文は称号ごとに2〜3通り(例:早とちり大王「3秒で振り向いて、お手つき」「開始3秒でガマンできなかった」)。

### 称号の名付け方
- **〜王・〜大王**:回数が一番の、ちょっと情けない記録(だまされ王・早とちり大王)。
- **〜大賞・〜賞**:目立った出来事を表彰する形(ウソつき大賞・ずっこけ大賞・まぶしかった賞)。
- **〜名人・〜の達人・〜職人・〜のプロ**:上手さ(本当に上手い/皮肉)をたたえる(振り向き名人・フェイクの達人・バナナ職人・体育座りのプロ)。
- **〜No.1**:一番を強調(鈍感力No.1・逃げ足No.1)。
- **〜の人・〜の被害者・〜の目撃者**:その場面に「いた人」として名付ける(あと一歩の人・バナナの被害者・カミナリの目撃者)。
- **ことわざ・慣用句のもじり**:正直者がバカを見た賞/信じる者は救われなかった賞/骨折り損/オオカミ少年。
- **職業・キャラクター**:名探偵・忍者・韋駄天。
- **ひとことの言いきり**:大ウソつき・粉まみれ・びしょぬれ・平和主義者・野生の勘。
- 子どもにも分かる言葉で、名前を聞いただけで「何があったか」が想像できるものにする。
- 英語名は短く自然な言い方(Big Fibber / So Close / Ninja)。直訳しない。
- 理由の文には必ず数字を入れる(「バナナで 3回転んだ」)。

## 13. 演出
- **振り向く瞬間**:「ザッ…」と集中線。当たりは「あったー!!」とファンファーレ、ハズレは「ガーン!」で顔のアップ → ひざから崩れて体育座り。
- **見逃し**:鬼が「トントン」→ 体ごと振り向く → 鬼の画面には相手のガーン!の顔、本人の画面には鬼のニヤニヤ顔 → 魂が抜けて「チーン」。
- **鬼の影**:鬼が後ろ3m以内に来ると、自分の前の床に影がのびる。
- **ドキドキ**:同じとき(鬼が後ろ3m以内)、BGM の下に心臓の「ドクン、ドクン」がうっすら鳴り、鬼の足音が少し大きくなり、画面のふちが少し暗くなる。近いほど速く・大きく・濃く。離れたら元に戻る。
- **お手つきの顔**:お手つきが重なるほど顔が崩れる(困り眉 → 汗 → 放心)。
- **投票の発表**:矢印・指マーク・スポットライト・「ジャジャーン」。

## 14. キャラ・きせかえ
- 丸い頭・カプセルの体・短い手足。体の色は10色かカラーコード。名前は8文字まで。
- 小物:帽子(キャップ・ニット帽・シルクハット)・メガネ(丸・四角)・リボン・豚の鼻。それぞれ9色。
- 鬼は黄色い帽子(海辺は麦わら帽子)。
- ボットの性格:せっかち(hasty)/慎重(careful)/うたがい屋(doubter)/おしゃべり(chatty)。

## 15. 音
- すべてプログラムで合成したオリジナル。言葉の入った声は使わない。
- 落とし物ごとの置く音(重いほど大きい)。フェイクは本物と完全に同じ音。鬼の足音は立体音響。
- BGM:ロビー(明るい曲)/教室(小学校っぽい曲)/海辺(ハワイアン)/夜の教室(ちょっと怖くてかわいい曲)/追いかけっこ(速い曲)/試合の終わり(行進曲)/記念写真(明るい曲)。
- 音量は「全体」「BGM」「効果音」を分けて調整できる。
